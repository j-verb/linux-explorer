# Linux Explorer

An interactive text-based terminal dashboard tool built in pure Bash to quickly lookup commands, reference manuals, and view live formatting cheat-sheet summary guides natively.

## 🚀 Features

* **Command Summary Frames**: Dynamic auto-sizing box frames displaying command descriptions and binary locations.
* **Integrated Lookups**: Fast execution shortcuts directly linked into local `man`, `tldr`, and online `cht.sh` streams.
* **Portable Architecture**: Inherits the user's local terminal font styles and color palettes automatically.

## 🛠️ Global System Installation

Clone this repository to your local machine, navigate inside the directory tracking workspace, and build it via the standard system Makefile:

```bash
git clone https://github.com
cd linux-explorer
sudo make install
```

## 📖 Usage Instructions

Invoke the explorer binary globally from any directory channel by passing any target binary argument:

```bash
linux-explorer grep
```

To remove the application bundle cleanly from your local file system, run:

sudo make uninstall
